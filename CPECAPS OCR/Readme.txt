Requirements:
pip install pillow google-genai

If you want to use Ollama:
pip install ollama

Notes:
It has a key linked to Enzo Linus Ong's Account, you can change the API key to something else if you want as long as it is Google's.
It also has a local Ollama option, thought it is less accurate and is slower since it is local so I didn't really implement it.
